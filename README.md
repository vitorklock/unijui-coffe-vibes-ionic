# ☕ Coffee Vibes

Bem-vindo ao **Coffee Vibes**, um aplicativo feito com **Ionic** que celebra o amor por café!  
Aqui você encontra receitas, curiosidades e o aroma digital do seu café favorito. ☕✨  

---

## 🚀 Pré-requisitos

Antes de rodar o projeto, você precisará ter instalado em sua máquina:

- [Node.js](https://nodejs.org/) (versão recomendada: **>= 16.x**)
- [npm](https://www.npmjs.com/get-npm) (geralmente vem junto com o Node)
- [Ionic CLI](https://ionicframework.com/docs/cli)

### 🔧 Instalando o Ionic CLI
Execute o comando abaixo no terminal:

```bash
npm install -g @ionic/cli
````

Para verificar se tudo foi instalado corretamente:

```bash
ionic --version
```

---

## 📦 Instalação do Projeto

Clone o repositório e instale as dependências:

```bash
git clone https://github.com/seu-usuario/coffee-vibes.git
cd coffee-vibes
npm install
```

---

## ▶️ Executando o App

Para rodar o projeto em ambiente de desenvolvimento:

```bash
ionic serve
```

Isso abrirá o aplicativo no seu navegador padrão (geralmente em `http://localhost:8100`).

---

## 📱 Outras opções úteis

### Rodar em dispositivo ou emulador:

```bash
ionic capacitor run android
```

ou

```bash
ionic capacitor run ios
```

### Gerar build de produção:

```bash
ionic build
```

---

## 💡 Dicas

* Se for a primeira vez usando o Ionic, siga o guia oficial:
  👉 [Documentação do Ionic Framework](https://ionicframework.com/docs)

* Caso encontre erros de permissão ao instalar globalmente pacotes npm no Linux/Mac, execute:

  ```bash
  sudo npm install -g @ionic/cli
  ```
